# Admin CRM Panel

React + Vite admin panel — Phase 4 (Week 10–12)

## Screens
- Dashboard — bookings, revenue, users, vendors, charts
- Category management — add/edit/delete categories & subcategories
- Vendor management — approve/reject/suspend vendors
- Listings management — feature, edit, assign categories
- Bookings management — all bookings, cancel, refund
- Payment & transaction logs — Razorpay status, refund tracking
- Coupon management — discounts, expiry, usage limits
- Reports & analytics — revenue reports, CSV export
- User management — view customers, ban/unban
